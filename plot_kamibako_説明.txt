plot_kamibako.py プログラム内容 詳細解説（詳細版）
================================================================

【概要】
紙箱（個装箱）の実測データをExcelファイルから読み込み、ロット（箱）ごとの
質量のばらつきを「ジッタープロット（jitter plot）」として可視化し、
PNG画像として出力するスクリプト。全96行、大きく5つの処理ブロックに
分かれている。

- 入力ファイル: コンタック個装箱.xlsx（列: ロット / 時刻 / 質量）
- 出力ファイル: 紙箱実測.png（解像度150dpi）
- 必要ライブラリ: pandas, numpy, matplotlib, openpyxl
  （openpyxlはpandasがxlsxファイルを読むために内部的に使う。
   pip install pandas numpy matplotlib openpyxl でインストール）
- 実行方法: 同じフォルダに「コンタック個装箱.xlsx」を置いた状態で
  `python plot_kamibako.py` を実行する。

【スクリプトが前提としているExcelの形（重要）】
- シート1枚目の1列目=ロット名、2列目=時刻、3列目=質量、という3列構成。
  （31行目で列名を強制的に上書きしているため、Excel側のヘッダー文字列
   が何であっても、列の並び順さえ合っていれば動作する）
- 質量列は数値（g）。空欄セルがあっても構わない（後で除外される）。
- 時刻列は「時:分」を含む値（Excelの時刻型でも文字列でも、文字列化
  して先頭5文字を切り出す実装のため、"12:20:00" のような形式や
  "12:20" 形式に対応できる）。
- 1つのロット（箱）につき複数行（例: 10枚分の測定値）が存在し、
  同じロット名の行が連続または分散して存在する想定。

ブロック0. 日本語フォントの設定（17〜24行目）
================================================================
コード:
    plt.rcParams["font.family"] = "Yu Gothic"      # 環境に合わせて変更
    plt.rcParams["axes.unicode_minus"] = False      # マイナス記号の文字化け防止

詳細:
- matplotlibはデフォルトでは日本語グリフを含まない欧文フォント
  （DejaVu Sans等）を使うため、日本語のタイトルや軸ラベル・凡例を
  そのまま描画すると「□□□」のような文字化け（トーフ）になる。
  これを防ぐために、OSに標準搭載されている日本語フォント名を
  matplotlibの全体設定（rcParams）に直接指定している。
- "Yu Gothic"（游ゴシック）はWindows 8.1以降に標準搭載。
  スクリプト冒頭のコメントで、Macなら"Hiragino Sans"、Linuxなら
  "Noto Sans CJK JP"や"IPAexGothic"に変更するよう案内されている
  （＝このスクリプトはWindows環境での実行を前提に書かれている）。
- axes.unicode_minus = False について:
  日本語フォントの多くはUnicodeのマイナス記号「−」(U+2212)の
  グリフを持たず、代わりに文字化けする。この設定をFalseにすると
  matplotlibは半角ハイフン「-」でマイナスを表現するようになり、
  軸の負の目盛りなどが正しく表示される。
- 注意点: rcParamsはグローバル（プロセス全体）設定のため、この
  スクリプト内で以降に作成する全てのFigure/Axesに適用される。
  指定したフォントがシステムにインストールされていない場合は
  警告が出て、デフォルトフォントにフォールバックする（文字化けの
  原因になり得る）。

ブロック1. データ読み込みと前処理（27〜38行目）
================================================================
コード:
    df = pd.read_excel("コンタック個装箱.xlsx")
    df.columns = ["ロット", "時刻", "質量"]          # 列名を統一
    df = df.dropna(subset=["質量"])

    # 時刻を "HH:MM" の文字列に整える
    df["時刻"] = df["時刻"].astype(str).str[:5]

    # ロットの出現順を保持（sortすると順番が狂うため）
    order = list(dict.fromkeys(df["ロット"]))

行ごとの解説:

1) df = pd.read_excel("コンタック個装箱.xlsx")
   - openpyxlエンジンを介してExcelブックの最初のシートを読み込み、
     pandas.DataFrameに変換する。1行目はヘッダー行として自動的に
     列名に使われる（デフォルト動作 header=0）。
   - カレントディレクトリ（スクリプト実行時の作業ディレクトリ）を
     基準にファイルを探すため、別フォルダから実行するとエラーになる
     （相対パス指定のため）。

2) df.columns = ["ロット", "時刻", "質量"]
   - Excel側のヘッダー文字列が何であっても（例: "Lot", "Time",
     "Weight(g)"等でも）、列の並び順が「1列目=ロット、2列目=時刻、
     3列目=質量」である前提で強制的に列名を上書きする。
   - もしExcelの列数が3列以外だった場合、ここで列数不一致の
     ValueErrorが発生する。

3) df = df.dropna(subset=["質量"])
   - 質量列がNaN（空欄・数値変換不可）の行を除外する。
   - Excel上で空白行や集計用の合計行などが混ざっていても、質量が
     入っていなければ自動的に解析対象から外れる安全策になっている。

4) df["時刻"] = df["時刻"].astype(str).str[:5]
   - 時刻列をいったん文字列型に変換し、先頭5文字だけを取り出す。
   - Excelのシリアル時刻（datetime.time型やTimestamp型）が
     pandasにより文字列化されると "12:20:00" のような形式になる
     ため、先頭5文字を取ると "12:20" が得られる。
   - 目的は、後段でx軸のラベルに「ロット名＋測定開始時刻」を
     "HH:MM" の短い形式で表示するため。

5) order = list(dict.fromkeys(df["ロット"]))
   - df["ロット"]列（Seriesとして各行のロット値の並び）を
     dict.fromkeys()に渡すと、値をキーとする辞書が作られる。
     Python 3.7以降、辞書はキーの挿入順序を保持する仕様のため、
     「重複を除去しつつ、初出順を保持したリスト」を作る定石的な
     イディオムになっている。
   - コメントにある通り、単純に df["ロット"].unique() や
     sorted(set(...)) を使うと、Excel上での測定順（＝時系列順）が
     アルファベット順や出現とは異なる順に並び替わってしまう
     おそれがあるため、意図的にこの方法を採用している。
   - このorderリストが、以降のループ処理・x軸の並び順の基準になる。

ブロック2. 箱ごとの平均質量の計算（41〜45行目）
================================================================
コード:
    means = np.array([df.loc[df["ロット"] == lot, "質量"].mean() for lot in order])
    rng_g = means.max() - means.min()               # 箱平均レンジ

詳細:
- リスト内包表記で order の各ロット lot について、
  df.loc[df["ロット"] == lot, "質量"] （そのロットに属する行だけの
  質量列＝Series）の .mean()（算術平均）を計算し、リストにまとめて
  from numpy.array() でNumPy配列 means に変換する。
  - means[i] は order[i] 番目の箱の平均質量（g）。
- rng_g = means.max() - means.min()
  - 全箱の平均質量のうち、最大値と最小値の差を計算。
  - これは「個々の測定値のばらつき」ではなく、「箱（ロット）単位で
    平均した値」同士のばらつき幅であり、変数名の通り
    「箱平均レンジ（Range of box means）」と呼ばれている。
  - 品質管理の文脈では、ロット間で平均値がどれだけ変動するかを
    見る指標（ロット間変動）に相当する。


================================================================
ブロック3. 作図処理（48〜91行目）
================================================================

--- 3-1. 図の初期化（51行目）---
    fig, ax = plt.subplots(figsize=(9.5, 5.4))
- 横9.5インチ×縦5.4インチ（≒24.1cm×13.7cm）のFigureとAxesを1つ
  作成。dpi未指定のためデフォルト100dpiで内部的に扱われるが、
  実際の保存時は後述のsavefigでdpi=150が指定される。

--- 3-2. レンジ帯の表示（54行目）---
    ax.axhspan(means.min(), means.max(), color="#EF9F27", alpha=0.08)
- axhspan(ymin, ymax, ...) は、y軸方向の指定範囲を、x軸全幅にわたって
  帯状に塗りつぶす関数。
- 全箱の平均質量の最小値〜最大値の範囲を、薄いオレンジ色
  （16進カラーコード #EF9F27）・不透明度0.08（ほぼ透明に近い薄さ）
  で塗ることで、「平均値がこの範囲内でばらついている」ことを
  背景として視覚的に示す下地になる。

--- 3-3. 乱数シードの固定（56行目）---
    rs = np.random.default_rng(7)                   # 乱数シード固定 → 毎回同じ図になる
- NumPyの新しい乱数生成API（Generator）を、シード値7で初期化。
- シードを固定することで、スクリプトを何度実行しても同じ「ジッター
  （ランダムな横方向のズレ）」パターンが再現され、図が毎回同じ見た目
  になる（バージョン管理や資料の再現性の観点で重要）。
- 従来のnp.random.seed()ではなくdefault_rng()を使う書き方は、
  NumPy推奨の最新スタイル（グローバル状態を汚さない、スレッドセーフ
  など利点がある）。

--- 3-4. 箱ごとのループ処理（58〜73行目）---
    for i, lot in enumerate(order):
        w = df.loc[df["ロット"] == lot, "質量"].values
- enumerate(order) により、インデックス i（0, 1, 2, ...）とロット名
  lot を同時に取り出しながら、箱の数だけループする。
- w = ... .values で、そのロットに属する質量の値をNumPy配列として
  取得（例: 1箱10枚なら要素数10の配列）。

  a) 実測点のジッター散布（61〜65行目）
     jitter = rs.uniform(-0.08, 0.08, len(w))
     ax.plot(np.full(len(w), i) + jitter, w,
             "o", ms=5, alpha=0.55, color="#2a78d6")
     - rs.uniform(-0.08, 0.08, len(w)) は、-0.08〜0.08の範囲の一様
       乱数を、その箱の測定点数ぶん生成する。
     - np.full(len(w), i) は、値iをlen(w)個並べた配列（＝全ての点の
       基本x座標をそのロットのインデックスiにする）。
     - この2つを足すことで、各点のx座標が「i ± 0.08の範囲内で
       ランダムにズレた値」になる。同じ質量・同じロットの点が
       縦一直線に重なって見えなくなり、分布の密集度（何点がどの
       重さ付近に集中しているか）が視覚的に分かりやすくなる。
       これが「ジッタープロット」と呼ばれる手法の核心部分。
     - "o" はマーカー形状（円）、ms=5はマーカーサイズ、alpha=0.55は
       半透明度（点が重なった箇所は色が濃く見える＝密度の目安にも
       なる）、color="#2a78d6" は青系統の色。

  b) 箱平均の横棒（68〜69行目）
     ax.plot([i - 0.24, i + 0.24], [w.mean()] * 2,
             color="#D95926", lw=3)
     - x座標を i-0.24 〜 i+0.24 の2点、y座標をその箱の平均値 w.mean()
       で同じ値2つとした線分を引く＝「その箱の位置に、平均値の高さで
       水平な太い線」を描画する。
     - color="#D95926"（濃いオレンジ・レンガ色）、lw=3（線幅3pt）で、
       散布点の青色と対比させ、平均値が一目で分かるようにしている。

  c) 平均値のラベル表示（72〜73行目）
     ax.text(i, w.mean() + 0.02, f"{w.mean():.3f}",
             ha="center", fontsize=9, color="#D95926", fontweight="bold")
     - 平均横棒のすぐ上（y方向に+0.02ずらした位置）に、平均値を
       小数点以下3桁でテキスト表示。
     - ha="center" でテキストをx=iを中心に水平中央揃え。
     - fontweight="bold" と平均線と同じ色（#D95926）で強調。

--- 3-5. レンジを示す両端矢印（75〜82行目）---
    x_arrow = len(order) - 0.55
    ax.annotate("", xy=(x_arrow, means.max()), xytext=(x_arrow, means.min()),
                arrowprops=dict(arrowstyle="<->", color="#C00000", lw=1.5))
    ax.text(x_arrow - 0.07, means.mean(),
            f"箱平均レンジ\n{rng_g:.3f} g\n＝大函 {rng_g*100:.0f} g",
            ha="right", va="center",
            fontsize=10, color="#C00000", fontweight="bold")
- x_arrow = len(order) - 0.55
  → 箱の本数から0.55を引いた位置、つまりグラフの一番右の箱よりも
    少し左寄りのx座標を、矢印を描く場所として決めている（右端の
    箱の散布点やラベルと重ならないようにするための調整値）。
- ax.annotate("", xy=..., xytext=..., arrowprops=dict(arrowstyle="<->", ...))
  → テキストなしのannotateを使い、xy（矢印の先端＝means.max()の
    高さ）とxytext（矢印の始点＝means.min()の高さ）の間に、
    両端矢印（"<->"）を描画するテクニック。arrowstyle="<->"は
    両方向に矢じりのある線を意味する。色は赤（#C00000）、線幅1.5pt。
    → 結果として「最も軽い箱の平均〜最も重い箱の平均」の間を結ぶ
      垂直な両矢印がグラフ右寄りに描かれる。
- 続くax.textで、矢印の少し左側（x_arrow - 0.07）、y方向は全箱
  平均のさらに平均位置（means.mean()）を基準に、
    "箱平均レンジ\n{rng_g:.3f} g\n＝大函 {rng_g*100:.0f} g"
  という3行のテキストを右揃え（ha="right"）・上下中央揃え
  （va="center"）で表示。
  - 1行目: ラベル「箱平均レンジ」
  - 2行目: レンジの実測値（例: 0.123 g のように g 単位、小数点3桁）
  - 3行目: rng_g*100 の値を整数で表示し、「＝大函 ○○ g」と表記。
    → これは、紙箱1枚あたりのレンジ（g）を100倍することで、
      「紙箱100枚を1つの大函（外装用の大きな箱）に梱包した場合に
      生じる重量差」に換算した参考値と考えられる（1大函=紙箱100枚
      という運用上の単位換算をこの1行で行っている）。

--- 3-6. 軸・タイトルの設定（84〜91行目）---
    ax.set_xticks(range(len(order)))
    ax.set_xticklabels(
        [f"{lot}\n({df.loc[df['ロット']==lot,'時刻'].iloc[0]})" for lot in order],
        fontsize=9)
    ax.set_ylabel("紙箱1枚の重量 (g)")
    ax.set_title("空紙箱の実測（5箱×10枚、12:20～13:40の80分内に測定）", fontsize=11.5)
    ax.grid(alpha=0.3, axis="y")
- set_xticks(range(len(order))): x軸の目盛り位置を、箱の数だけ
  0,1,2,...と整数位置に設定（各箱のインデックスiと一致させる）。
- set_xticklabels(...): 各目盛りに表示するラベルを、
    "{ロット名}\n({そのロットの最初の行の時刻})"
  という2行構成の文字列にする。
  df.loc[df['ロット']==lot,'時刻'].iloc[0] は、そのロットに属する
  行の「時刻」列の先頭値（＝そのロットの測定を開始した時刻）を
  取り出している。これにより、x軸のラベルが「ロット名＋測定開始
  時刻」の2段表示になり、いつ測定した箱かが一目で分かる。
- set_ylabel("紙箱1枚の重量 (g)"): y軸の単位・意味を明示。
- set_title(...): グラフ上部に測定条件（5箱×10枚、12:20〜13:40の
  80分間で測定したこと）を明記し、グラフ単体でも文脈が伝わるように
  している。
- grid(alpha=0.3, axis="y"): y軸方向（横線）のグリッドのみを薄く
  （不透明度0.3）表示し、x軸方向の縦線は出さない。値の高さを
  読み取りやすくしつつ、箱同士の区切りを視覚的にうるさくしない
  ための選択。

  処理が正常終了したことをユーザーに知らせる。

【補足: 使われている主な技術要素の整理】

  同じ値の配列生成（np.full）
- matplotlib:
  - 散布・線描画: ax.plot（マーカー"o"での散布と、線分としての平均線
    の両方に同じplot関数を使い分けている）
  - 帯塗り: ax.axhspan
  - テキスト注釈: ax.text
  - 矢印注釈: ax.annotate（矢印専用にテキストなしで使うテクニック）
  - 軸設定: set_xticks / set_xticklabels / set_ylabel / set_title /
    grid
  - レイアウト調整・保存: tight_layout, savefig

【補足: このグラフが伝えたいこと（データ解釈の観点）】
- 横軸: 測定した箱（ロット）を測定順に並べたもの。ラベルに測定
  開始時刻も併記することで、時間経過に伴う変化も追える。
- 縦軸: 紙箱1枚あたりの重量(g)。
- 青い散布点: 各箱内での1枚ごとの実測値のばらつき（箱内変動）。
- オレンジの横棒とラベル: 箱ごとの平均値（代表値）。
- 薄いオレンジの帯と赤い両矢印・注記: 箱間で平均値がどれだけ
  変動しているか（箱間変動＝箱平均レンジ）、およびそれを紙箱100枚
  単位（大函）に換算した場合の重量差の目安。
- 全体として、「同じ仕様の紙箱でも、測定した箱（ロット）や時間帯に
  よって平均重量にどの程度の差が生じているか」を、箱内・箱間の
  両方のばらつきを同時に可視化して品質管理・工程解析に役立てる
  ためのグラフである。
