========================================
1. はじめに
========================================
このツールは、重量チェッカーが出力するCSV／txtデータを読み込み、
ロット単位（1回の製造分）で統計分析を行い、グラフと統計数値をまとめた
Excelファイルを自動生成するものです。

日常の品質管理に活用することで、製造工程のばらつきや不良の傾向を
素早く把握できます。


========================================
2. 対応しているデータ形式
========================================
このツールは以下の4種類のデータ形式に対応しています。

  ① アンリツ製　重量チェッカー（CSV）
     CSVの列に「測定値(g)」「ランクコード」が含まれる形式。

  ② イシダ製　重量チェッカー（CSV）
     CSVの先頭10行がヘッダー情報になっている形式。

  ③ 旧イシダ製　重量チェッカー（CSV／WeightLog形式）
     機種によってヘッダーが文字化けして読み取れないため、列の位置
     （1列目=日付、2列目=時刻、5列目=品種番号、7列目=測定値(g)、
     8列目=振分ステータス）から自動判定する形式。
     振分ステータス　1=OK／2=軽量／3=過量／16=NG（外部1判定＝重量以外の
     不良として弾かれたもの）。

  ④ WC計量機のtxt出力（txtファイル）
     測定1件ごとの「No. 値」だけが並ぶシンプルな形式。
     この形式には次の情報が含まれていません。
       ・測定1件ごとの時刻 → グラフの横軸は時刻ではなく「測定順序」になる
       ・品種番号            → ファイル名にも品種名は付かない
       ・軽量／過量の区別    → 不良は「OK」か「NG」のどちらかのみ
     ファイル冒頭に日付時刻（例：2026-Jul-02 10:30）があれば、それを
     ロット名として利用します。無い場合はファイル名をそのままロット名
     として使います。

  ※ 上記以外のメーカーのCSVには対応していません。
  ※ CSVファイルとtxtファイルを同時に選択することはできません
    （選択するとエラーになります）。どちらか一方ずつ実行してください。


========================================
3. 出力されるファイル
========================================
解析完了後、デスクトップに以下の形式でExcelファイルが保存されます。

  ・CSV（品種番号あり）の場合：
      分析結果_2026-07-01製造_品種番号1 ロット1_20260701_1430.xlsx
      → 複数ロットに分割した場合は、ロットの数だけExcelファイルが
        作成されます。

  ・txtファイルの場合：
      分析結果_2026-07-02 10:30 測定_20260702_1445.xlsx
      （ファイル冒頭に日付が無い場合はファイル名がロット名になります）
      → txtファイルは1ファイル＝1ロットとして扱われるため、選択した
        txtファイルの数だけExcelファイルが作成されます。


========================================
4. 基本的な使い方（CSVファイルの場合）
========================================
 ①  「WC分析ツール.exe」をダブルクリックして起動します。
     小さなウィンドウが中央に表示されます。

 ②  「CSV/txt選択して解析」ボタンをクリックします。
     ファイル選択ダイアログが開きます。

 ③  解析したいCSVファイルを選択して「開く」をクリックします。
     Ctrlキーを押しながらクリックすると複数ファイルをまとめて選択
     できます。また、CSVが入ったフォルダを指定することも可能です。

 ④  「ロット分割プレビュー」画面が表示されます。
     ロットの区切りとなる空き時間（しきい値）を選択し、内容を
     確認してください。（詳しくは「6. ロット分割プレビュー画面の
     説明」を参照）

 ⑤  「この分割でOK」ボタンをクリックします。
     分析が実行され、デスクトップにExcelファイルが保存されます。

 ⑥  完了メッセージが表示されたら終了です。
     デスクトップのExcelファイルを開いて分析結果を確認してください。

 ※ 品種番号が異なるCSVを一緒に選択すると、続けてよいか確認する
   ダイアログが表示されます。


========================================
5. 基本的な使い方（txtファイルの場合）
========================================
txtファイルはCSVと違い、品種番号や測定ごとの時刻が無いため、
「ロット分割プレビュー」画面は表示されません。選択した1ファイルが
そのまま1ロットとして扱われ、すぐにExcelが作成されます。

 ①  「WC分析ツール.exe」をダブルクリックして起動します。

 ②  「CSV/txt選択して解析」ボタンをクリックします。

 ③  解析したいtxtファイルを選択して「開く」をクリックします。
     複数ファイルをまとめて選択すると、ファイルごとにExcelが
     1つずつ作成されます。

 ④  そのまま解析が実行され、デスクトップにExcelファイルが
     保存されます（プレビュー画面は表示されません）。

 ⑤  完了メッセージが表示されます。
     ・作成できたファイルの件数
     ・OKデータ不足でスキップされたファイル（OKデータが2件未満）
     ・読み込みに失敗したファイル
     がまとめて表示されるので、内容を確認してください。

 ※ txt由来のデータは「軽量」「過量」の区別ができないため、不良は
   すべて「NG」として集計・表示されます。
 ※ 測定ごとの時刻情報が無いため、グラフの横軸は「測定順序」になり、
   「開始時刻／終了時刻／製造時間」は「−」と表示されます。


========================================
6. ロット分割プレビュー画面の説明（CSV専用）
========================================
CSVファイルを読み込むと「ロット分割プレビュー」が表示されます。
測定データの時間的な空き（インターバル）を基準に、1回の製造分
（ロット）を自動で検出します。

6-1. しきい値の選択
  「この時間以上データが空いたら新しいロット」というしきい値を
  以下のボタンから選びます。
      10分 / 15分 / 30分（初期値）/ 45分 / 1時間
  ボタンを切り替えると、プレビューのロット一覧がリアルタイムで
  更新されます。
  ※ 製造の合間の休憩や品種切り替えの時間に合わせてしきい値を
    調整してください。

6-2. プレビュー一覧の見方
  品種       … CSVに記録されていた品種番号
  ロット     … 自動で付けたロット番号（ロット1, ロット2 …）
  開始時刻   … そのロットで最初に測定した時刻
  終了時刻   … そのロットで最後に測定した時刻
  総件数     … ロット全体の測定数
  OKデータ件数 … ランク「正量（OK）」と判定された件数
  状態       … ✓ 分析対象 … 正常に解析されます
                ⚠ スキップ予定 … OKデータが少なすぎて統計計算が
                できないため、Excelは作成されません

  ※ 「⚠ スキップ予定」が表示されたロットは、しきい値を小さくして
    隣のロットと統合するか、CSVの内容をご確認ください。

6-3. ボタンの説明
  この分割でOK       … 表示されている分割でExcelを作成します
  ロット分割しない   … すべてのデータを1ロットとして扱い、
                        Excelを1つだけ作成します
  キャンセル         … 分析を中止してメイン画面に戻ります


========================================
7. 出力されるExcelファイルの見方
========================================
このエクセルファイルは、重量チェッカーで測定したデータを自動で
集計・グラフ化したものです。ロットごとに1つのファイルが作成されます。

まず最初に見るシート：「分析レポート」
----------------------------------------
ファイルを開くと一番左に「分析レポート」というシートがあります。
統計数値・ランクコード集計・グラフがすべてここにまとまっているので、
基本的にはこのシートだけ見れば大丈夫です。


7-1. シート一覧
----------------------------------------
  分析レポート               … 統計数値・グラフが1枚にまとまった
                                メインシート（A4縦で印刷可能）
  全データ時系列             … 全データ（OK・軽量・過量・NG）の
                                時系列グラフ（拡大表示用）
  全データ                   … 測定した全件の生データ
                                （測定値出力No.・日付時刻・測定値・
                                ランクコードの4列。軽量・過量・NGの
                                行は赤色で表示）
  ヒストグラム（OK品のみ）   … OK品の重さ分布グラフ（拡大表示用）
  時系列チャート（OK品のみ） … OK品だけの時系列グラフ（拡大表示用）
  全OKデータ                 … OK品の生データ一覧
                                （±3σ外れ値行は赤色で表示）
  全外れ値（±3σ超）         … ±3σの範囲を超えたOK品の一覧


7-2. 「分析レポート」シートの数値の見方
----------------------------------------

【基本統計】
  全数          … 測定した個数（全部の件数）
  OK数          … 正量（合格）と判定された個数
  NG数          … 軽量・過量・NGだった個数
  不良率(%)     … NG数 ÷ 全数 ×100。この数字が大きいほど不良が多い

【製造情報】
  開始時刻／終了時刻／製造時間 … そのロットを作っていた時間帯
  （txt由来のデータには時刻情報が無いため「−」と表示されます）

【統計値（OK品のみ）】
  平均(g)          … OK品だけの重さの平均値
  標準偏差(g)      … 重さのばらつきの大きさ。小さいほど安定して
                      同じ重さに仕上がっている
  Max(g)／Min(g)   … OK品の中で一番重かった／軽かった値
  下限−3σ／上限+3σ … 「平均からどれくらいまでのばらつきなら通常
                      範囲か」を示す目安の線。統計的には、ここから
                      はみ出るデータは1000個に3個ほどしか出ないはずの
                      「珍しい値」という意味になる
  外れ値件数       … 上の±3σの範囲からはみ出したOK品の個数
                      （多い場合は工程に何か変化があった可能性）

【ランクコード集計】
  OK        … 正量（合格）
  軽量      … 規定より軽かったもの
  過量      … 規定より重かったもの
  ２個乗り  … 2個が重なって計量されたと判定されたもの
  NG        … 軽量・過量の区別ができない不良判定
              （txt由来データ、または旧イシダの外部判定16由来）


7-3. グラフの見方（分析レポートシートに埋め込まれています）
----------------------------------------

【全データ時系列】
  OK・軽量・過量・NGをすべて時間順（またはtxtの場合は測定順）に
  表示するグラフです。
    青丸         ：OK品
    オレンジ▽（下三角）：軽量
    赤△（上三角）：過量
    赤×印        ：NG（txt由来／旧イシダの外部判定。軽量・過量の
                     区別なし）
    赤い実線     ：OK品の平均値
    オレンジ破線 ：±3σの範囲（OK品のみで計算）
  不良がどの時間帯（測定順）に出ているかを見るのに使います。

【時系列チャート（OK品のみ）】
  OK品だけを時間順（またはtxtの場合は測定順）に並べたグラフです。
    青丸        ：OK品
    赤い×印    ：外れ値（OK判定だが±3σを超えた重量の品）
                  最も重い外れ値・最も軽い外れ値には重量の数値が
                  表示される
    赤い実線    ：OK品の平均値
    オレンジ破線：±3σの範囲（このはみ出しが多いと工程が
                  安定していない）

【ヒストグラム（OK品のみ）】
  OK品の重さの分布を山型グラフで表示したもの。


========================================
8. よくある質問とトラブル対応
========================================
Q. ロットがうまく分かれない（CSV）
  しきい値を変更してください。製造と製造の間の休憩時間より少し
  短い値を設定するとうまく分割できます。
  また、複数日分のCSVを混ぜると意図しない結合が起きることが
  あります。1日ごと・品種ごとにCSVを分けて読み込むことを
  おすすめします。

Q. 「⚠ スキップ予定」が出て困る／完了メッセージにスキップと出た
  OKデータが2件以上ないと統計計算できないためスキップされます。
  CSVの場合はしきい値を小さくして隣のロットと統合するか、内容を
  ご確認ください。
  各ロットの先頭・末尾に計量機の点検用として軽量品・過量品の
  サンプルをわざと流す運用をしている場合、それによる異常値の
  混入は正常な動作です。

Q. 複数のCSV／txtをまとめて解析したい
  ファイル選択ダイアログでCtrlキーを押しながら複数ファイルを
  クリックするとまとめて選択できます。CSV／txtが入ったフォルダを
  選択することも可能です。ただしCSVとtxtを混在させて選択すると
  エラーになるため、どちらか一方だけを選んでください。

Q. 品種番号が違うCSVが混在していた
  品種番号が異なるCSVを一緒に読み込もうとすると確認ダイアログが
  表示されます。同じ品種のCSVだけを選択し直してください。
  ※ 品種番号は重量チェッカーの号機ごとに独立しているため、別の
    号機で同じ品種番号が使われることがあります。CSV自体には
    号機を識別する情報が含まれていないので、フォルダやファイルを
    号機ごとに分けて管理することをおすすめします。

Q. 「未対応のCSVフォーマットです」というエラーが出る
  対応しているのはアンリツ・イシダ・旧イシダ製の重量チェッカーの
  CSVのみです。他のアプリで加工・保存したCSVは読み込めない場合が
  あります。重量チェッカーから直接エクスポートしたCSV／txtを
  ご使用ください。

Q. Excelファイルが保存される場所が分からない
  デスクトップに自動保存されます。
  ファイル名の形式：
    CSV … 分析結果_[日付]製造_[品種] [ロット]_[実行日時].xlsx
    txt … 分析結果_[ロット名]_[実行日時].xlsx

Q. 不良率が高い・外れ値が多い
  「全データ時系列」グラフで、不良が増え始めた時間帯（測定順）を
  確認してください。特定の時間帯に集中している場合は、その
  時間帯に何か工程変化があった可能性があります。
  ロットの両端に外れ値が出るのは、点検用サンプルによる正常な
  動作であることが多いので、まずはその可能性を確認してください。


========================================
9. 付録：統計用語集
========================================
エクセルファイルに出てくる言葉をやさしく説明します。


------------------------------------------------------------
【 平均 (g) 】
------------------------------------------------------------
〈意味〉
  全部の重さを足して、個数で割った値。「だいたいこのくらいの重さ」
  という中心を示す数字。

〈例〉
  5個の重さが 100, 101, 99, 102, 98 (g) だった場合：
  → 合計 500 ÷ 5個 ＝ 平均 100.0 g

〈エクセルでの見方〉
  OK品だけを使って計算しています。
  日によって平均が大きくずれている場合は、原材料や設備に変化が
  あった可能性があります。


------------------------------------------------------------
【 標準偏差 (g)　記号：σ（シグマ）】
------------------------------------------------------------
〈意味〉
  重さのばらつきの大きさを表す数字。
  「平均からどれくらい外れるのが普通か」を示す。

  ・σ が小さい → 重さがそろっている（良い状態）
  ・σ が大きい → 重さがバラバラ（工程が不安定な可能性）

〈例〉
  平均 100 g、標準偏差 0.2 g の場合：
  ほとんどの製品が 99.4〜100.6 g（平均 ± 3σ の範囲）に収まっている

〈エクセルでの見方〉
  グラフの「オレンジ破線」が ±3σ の位置に引かれています。
  この線から大きく外れている点があれば要注意です。


------------------------------------------------------------
【 ±3σ（プラスマイナス3シグマ）/ 下限・上限 】
------------------------------------------------------------
〈意味〉
  「平均から標準偏差の3倍分だけ上下に引いた線」のこと。
  この範囲に入らない製品は、統計的にみて非常に珍しい重さをしている。

  下限 −3σ ＝ 平均 − (標準偏差 × 3)
  上限 +3σ ＝ 平均 + (標準偏差 × 3)

〈例〉
  平均 100 g、標準偏差 0.2 g の場合：
  下限 −3σ ＝ 100 − (0.2 × 3) ＝ 99.4 g
  上限 +3σ ＝ 100 + (0.2 × 3) ＝ 100.6 g

〈なぜ3倍なのか〉
  統計的に、ランダムなばらつきの場合：
  ・±1σ の範囲に 68% の製品が入る
  ・±2σ の範囲に 95% の製品が入る
  ・±3σ の範囲に 99.7% の製品が入る
  → ±3σ を超えるのは 1000個に約3個しかない「異常に珍しい」値。
     これが頻繁に出ている場合は、工程に何か問題がある可能性が高い。

〈エクセルでの見方〉
  「下限 −3σ (g)」「上限 +3σ (g)」の数値が分析レポートに
  表示されます。グラフのオレンジ破線がこの位置に対応しています。


------------------------------------------------------------
【 外れ値 / 外れ値件数 】
------------------------------------------------------------
〈意味〉
  OK判定（正量）だったにもかかわらず、±3σ の範囲を超えていた製品。
  重量チェッカーは「OK」と通したが、統計的にみると異常に重い・
  軽い個体。

〈なぜ重要なのか〉
  重量チェッカーの合否ラインは上下限値で設定した範囲で判定します
  が、WC分析ツールは「その日その製品のばらつきから見て異常かどうか」
  を別の基準で判断します。
  外れ値が多い時間帯には、何かトラブルが起きていた可能性があります。

〈エクセルでの見方〉
  時系列チャート（OK品のみ）のグラフで「赤い×印」が外れ値です。
  外れ値の一覧は「全外れ値（±3σ超）」シートで確認できます。


------------------------------------------------------------
【 不良率 (%) 】
------------------------------------------------------------
〈意味〉
  全測定個数のうち、NG（軽量・過量・NG判定）だった割合。

  不良率 ＝ NG数 ÷ 全数 × 100

〈例〉
  全数 10,000個のうち NG が 5個 の場合：
  → 5 ÷ 10,000 × 100 ＝ 0.05%

〈エクセルでの見方〉
  NG数が多くても全数が多ければ不良率は低くなります。
  逆に NG数が少なくても全数が少なければ不良率は高くなります。
  他のロットや日付と比較するときは不良率で比べるとわかりやすい。


------------------------------------------------------------
【 ヒストグラム（分布グラフ）】
------------------------------------------------------------
〈意味〉
  製品の重さをいくつかの「重さの帯」に分けて、それぞれ何個あった
  かを棒グラフで表したもの。製品の重さがどう分布しているかを
  一目で確認できる。

〈見方〉
  正常な場合 → 山が1つで、平均のあたりに中心がある（ベルの形）
  異常なケース：
  ・山が2つある → 条件の違う2種類の製品が混ざっている可能性
  ・山が左右に偏っている → 充填量の調整がずれている可能性
  ・裾が長い → 極端に重い・軽い個体が混在している可能性


------------------------------------------------------------
【 時系列チャート 】
------------------------------------------------------------
〈意味〉
  製品を測定した時刻（横軸）と重さ（縦軸）を点でプロットした
  グラフ。製造中に重さがどう変化したかを時間順に追える。
  （txt由来のデータには時刻が無いため、横軸は「測定順序」になる）

〈見方〉
  ・点が全体的に上にずれてくる → 製品が少しずつ重くなっている
  ・点が急に上下に散らばる    → その時間帯に何かトラブルがあった
                                  可能性がある
  ・特定の時刻に×印が集中する → その時刻に異常品が出ていた

〈種類〉
  OK品のみ ：合格品だけのグラフ。ばらつきや外れ値の確認に使う
  全データ  ：OK・軽量・過量・NGすべてを表示。不良の発生
              タイミングの確認に使う


------------------------------------------------------------
【 ランクコード 】
------------------------------------------------------------
〈意味〉
  重量チェッカーが各製品に付けた判定の区分。

  OK（正量）  … 規定の重さの範囲内。合格品
  軽量        … 規定より軽かった。内容物の欠品・抜けが疑われる
  過量        … 規定より重かった。内容物の入れすぎ・異物が疑われる
  ２個乗り    … 2個が重なった状態で測定されたと判定。参考値として
                扱う
  NG          … 軽量・過量の区別ができない不良判定
                （txt由来データ、旧イシダの外部判定16由来）

〈エクセルでの見方〉
  ランクコード集計で各区分の件数・比率が確認できます。
  全データシートの D列 に各製品のランクコードが記録されています。


------------------------------------------------------------
【 信頼区間（95%CI）】
------------------------------------------------------------
〈意味〉
  「本来の（母集団の）平均はこの範囲にある可能性が高い」という
  推定区間。今回測定できたのはあくまで一部のサンプルなので、
  本当の平均値には多少の幅を持たせて考える、という統計的な
  考え方。
  現在のところツール内部の計算にのみ使われており、Excel上には
  数値として表示されません。


------------------------------------------------------------
【 まとめ：数字のつながり 】
------------------------------------------------------------

  全数 ─┬─ OK数（正量）────→ 平均・標準偏差・Max/Min を計算
        │                      ↓
        │                  ±3σ を計算
        │                      ↓
        │                  外れ値を抽出（OK品の中で±3σ超）
        │
        └─ NG数（軽量+過量+NG）→ 不良率 を計算

  ・不良率が高い   → NG品の発生タイミングを「全データ時系列」で確認
  ・外れ値が多い   → OK品の中の異常を「時系列チャート（OK品のみ）」
                      で確認
  ・σが大きい     → ばらつきの原因を調査
